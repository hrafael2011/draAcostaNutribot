PDF de demostración del entregable (plantilla malva / WeasyPrint).

Archivo: example/plan_nutricional_entregable_ejemplo.pdf

Generar de nuevo (requiere backend con WeasyPrint instalado):
  cd backend && PYTHONPATH=. python scripts/render_example_entregable.py

Este PDF está excluido del patrón global *.pdf en .gitignore para que aparezca en el explorador del IDE.
Si no lo ves, abre la carpeta example en el sistema de archivos o ejecuta el script y revisa la ruta que imprime.
